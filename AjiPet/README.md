# Aji Pet

사진 속 강아지를 바탕으로 만든 macOS 로컬 데스크톱 펫입니다.

## 실행

상위 폴더의 **Aji Pet.app**을 더블 클릭하세요. 화면 아래에 강아지가 나타나고 메뉴 막대에 발바닥 아이콘이 표시됩니다.

- 혼자 좌우로 산책하고, 앉아 쉬거나 잠을 잡니다.
- 강아지를 클릭하면 하트로 반응합니다.
- 드래그하면 원하는 위치로 옮길 수 있습니다.
- 강아지 우클릭 또는 메뉴 막대의 발바닥 아이콘에서 산책, 낮잠, 일시정지, 크기, 숨기기, 종료를 선택할 수 있습니다.
- 화면 밖으로 이동했을 때는 **화면 아래로 데려오기**를 선택하세요.

실행 중에는 인터넷, 계정, API 키가 필요하지 않습니다. 로그인 시 자동 실행은 설정하지 않았습니다. AI로 만든 캐릭터와 로컬 애니메이션을 사용하는 앱이며 대화형 언어 모델은 포함하지 않습니다.

이 Mac용으로 빌드하고 로컬 서명한 앱입니다. 다른 Mac에 배포하기 위한 Apple 공증은 하지 않았습니다.

## 소스와 이미지

- `Sources/main.swift`: 네이티브 AppKit 앱
- `Assets/pet-sheet.png`: 투명 배경 캐릭터 이미지
- `image-prompt.txt`: 내장 image_gen 도구에 전달한 제작 프롬프트
- `build.command`: Command Line Tools가 설치된 Mac에서 다시 빌드
